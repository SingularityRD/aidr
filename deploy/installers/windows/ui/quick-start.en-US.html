Singularity AIDR quick start

Singularity AIDR checks what your AI coding tools do (commands, files and web requests) and stops harmful actions before they run.

1. Restart your AI tools

Setup connected Singularity AIDR to the AI tools it found for your account (Claude Code, Cursor, VS Code, Codex, OpenCode, OpenClaw). A tool that was already open uses the protection after a restart.

  • Cursor and VS Code: run Singularity AIDR: Enable protection from the command palette.
  • Codex: trust the hooks once with /hooks in Codex.

2. Check that it works

Open a new terminal (the folder of the aidr command was just added to your PATH) and run:

  1. aidr status shows which AI tools are protected and what is still needed.
  2. aidr verify sends a harmless test through each connected tool and reports PASS or FAIL.

The Setup Assistant walks you through the same steps: aidr assistant.

3. When something is blocked

The message in your AI tool says why Singularity AIDR stopped the action and what you can do next. Approving a blocked action is done by a person outside the AI tool, never by the AI tool itself.

4. Installed an AI tool later?

Run aidr setup once in a terminal. It connects Singularity AIDR to the new tool.

5. Updates and removal

  • aidr update --check shows whether a newer version is available; aidr update installs it after checking its signature.
  • To remove Singularity AIDR, use Windows Settings > Apps > Singularity AIDR > Uninstall.
