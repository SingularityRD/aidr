# Worker: Frontend Implementation

## Procedure

### Before Starting
1. Read mission.md for context
2. Read AGENTS.md for constraints
3. Run `pnpm install` if needed

### Implementation
1. Create React/TypeScript components
2. Use Tailwind for styling
3. Add error boundaries
4. Ensure accessibility

### Before Committing
1. Run `pnpm lint`
2. Run type checks: `pnpm check`
3. Test manually if needed

### Handoff Requirements
- Components created
- Any UI/UX decisions made
- Responsive design verified
