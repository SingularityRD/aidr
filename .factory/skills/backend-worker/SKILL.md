# Worker: Backend Implementation

## Procedure

### Before Starting
1. Read mission.md for context
2. Read AGENTS.md for constraints
3. Run `pnpm install` if needed
4. Check .factory/services.yaml for commands

### Implementation
1. Create backend features per features.json
2. Use TypeScript strict mode
3. Add tests for each feature
4. Run `pnpm lint` and `pnpm check`

### Before Committing
1. Run tests: `pnpm test`
2. Add changeset if needed: `pnpm changeset`
3. Commit with descriptive message

### Handoff Requirements
- What was implemented
- Any blockers or issues
- Tests added/updated
- Documentation updated
