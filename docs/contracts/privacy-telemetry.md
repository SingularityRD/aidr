# Contract: Browser Guard -> AIDR control plane privacy telemetry (fixed; both sides must follow exactly)

Transport: POST {controlPlaneBaseUrl}/functions/v1/ingest
Headers: Authorization: Bearer <Browser Guard ingest-only key (`aidr_ingest_...`, scope `ingest:browser_guard`; a tenant `aidr_live_...` key is still accepted)>, Content-Type: application/json
Credential: deploy an `ingest:browser_guard` key (dashboard API Keys -> "Browser Guard ingest-only key", owners/admins). Managed browser policy is readable by the profile's user (chrome://policy), so the key is treated as disclosed: /v1/ingest accepts it only with agent_runtime "browser_guard" and only privacy_scan events (anything else -> 403 api_key_scope_denied / event_type_not_permitted), budgets it per key (AIDR_BROWSER_KEY_INGEST_RL_PER_MIN, default 6000 events/min), registers at most its install_limit distinct iids (-> 403 install_limit_exceeded), never lets it take over an agent of another runtime (-> 403 agent_runtime_mismatch), and answers with a delivery acknowledgement only (no signed entitlement). Every other API-key endpoint refuses it (403 api_key_scope_denied).
Body envelope (same envelope other connectors use):
{
  "iid": "<stable per-install UUID generated by the extension, stored in chrome.storage.local>",
  "agent_runtime": "browser_guard",
  "agent_runtime_version": "<browser family and major version, e.g. chrome-126 | edge-126 | firefox-128>",
  "aidr_version": "<extension version, e.g. 1.0.0>",
  "events": [
    {
      "event_id": "bg:<uuid>",
      "event_type": "privacy_scan",
      "timestamp": "<ISO-8601>",
      "site": "chatgpt|gemini|claude|copilot|perplexity|deepseek|mistral|grok|other",
      "action": "masked|blocked|warned|allowed",          // what the guard did to the outgoing prompt/paste/file
      "channel": "prompt|paste|file",
      "entity_counts": { "EMAIL": 2, "TC_KIMLIK": 1 },     // keys = privacy ENTITY_TYPES; integers 1..100000; max 32 keys
      "findings_count": 3,                                   // integer 0..1000000
      "policy_id": "<optional identifier matching ^[A-Za-z0-9][A-Za-z0-9._:-]{0,127}$>"
    }
  ]
}
Rules: NO raw text, NO masked text, NO values, NO URLs beyond the site enum. Max 200 events per batch. Server maps action->decision for generic views: masked=>allow (redacted), warned=>ask, blocked=>deny, allowed=>allow.
Server response: existing ingest response shape (2xx with accepted count). Client retries with exponential backoff, keeps a bounded local queue (max 500 events), drops oldest on overflow, and never blocks the user's typing on telemetry.
Enrollment in the extension: options page (or managed policy keys controlPlaneUrl + apiKey) -> stored in chrome.storage.local; managed policy wins.
