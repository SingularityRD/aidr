# Branding

`singularity-mark.svg` is the round Singularity product mark (a disc split by a fan of five
tapered rays that converge at the bottom). It uses `currentColor`, so it renders black on light
surfaces and can be recoloured by CSS. Generate app and extension icons from this file; do not
redraw the mark per package.

Status: vector redraw approved as a draft on 2026-10-15; replace with the designer's master file
when it is available, keeping the same file name.
